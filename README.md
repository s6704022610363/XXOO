# เกม XO 3x3 (Tic-Tac-Toe Web App) - ระบบยืนยันตาเดิน & จับเวลา 1 นาที

เว็บแอปพลิเคชันเกม XO (Tic-Tac-Toe) ขนาด 3x3 สำหรับ 2 ผู้เล่น พร้อมระบบกดยืนยันตาเดิน (Stage & Confirm), ระบบจับเวลารอบละ 1 นาที (Turn Timer), ปุ่มหยุดเกมชั่วคราว (Stop / Resume), ระบบบันทึกประวัติ และการตั้งค่าชื่อผู้เล่น

---

## 🎯 วิธีเปิดรันใน VS Code ให้ได้ 100% (เลือกวิธีที่สะดวกได้เลย)

### ✨ วิธีที่ 1: ดับเบิ้ลคลิกไฟล์รันอัตโนมัติ (ง่ายที่สุด ไม่ต้องพิมพ์คำสั่ง)
- **สำหรับเครื่อง Mac:** ดับเบิ้ลคลิกที่ไฟล์ **`start.command`** (ระบบจะติดตั้งและเปิดหน้าเว็บให้อัตโนมัติ)
- **สำหรับเครื่อง Windows:** ดับเบิ้ลคลิกที่ไฟล์ **`start.bat`**

---

### 💻 วิธีที่ 2: รันผ่านปุ่ม Run / Debug ใน VS Code (F5)
1. เปิดโฟลเดอร์โปรเจกต์นี้ใน **VS Code**
2. กดปุ่ม **`F5`** บนคีย์บอร์ด (หรือคลิกแท็บ **Run & Debug** รูปไอคอน Play ด้านซ้าย > เลือก **"🚀 รันเกม XO"**)
3. VS Code จะทำการรัน Server และเปิดหน้าเว็บให้ทันที

---

### ⌨️ วิธีที่ 3: รันผ่าน Terminal ใน VS Code (วิธีมาตรฐาน)

#### ขั้นตอนที่ 1: เปิด Terminal ใน VS Code
- กดคีย์ลัด: **`` Ctrl + ` ``** (เครื่อง Mac: **`` Cmd + ` ``**)
- หรือไปที่เมนูด้านบนของ VS Code: **`Terminal`** > **`New Terminal`**

#### ขั้นตอนที่ 2: ติดตั้ง Dependencies (ทำครั้งแรกครั้งเดียว)
พิมพ์คำสั่งนี้ใน Terminal แล้วกด `Enter`:
```bash
npm install
```
*(รอประมาณ 10–20 วินาที ให้ระบบดาวน์โหลดโฟลเดอร์ `node_modules` จนเสร็จ เส้นสีแดงทั้งหมดในไฟล์จะหายไปทันที)*

#### ขั้นตอนที่ 3: สั่งรันเว็บแอปพลิเคชัน
พิมพ์คำสั่ง:
```bash
npm run dev
```

เมื่อรันสำเร็จ จะปรากฏข้อความ:
```
  VITE v6.2.3  ready in 250 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: http://0.0.0.0:3000/
```
👉 ให้กดปุ่ม `Ctrl + คลิก` ที่ลิงก์ **`http://localhost:3000`** หรือเปิดเว็บเบราว์เซอร์ (Chrome / Safari / Edge) แล้วพิมพ์:
```
http://localhost:3000
```
เพื่อเริ่มเล่นเกมได้ทันที!

## ❓ แก้ปัญหาเบื้องต้น (FAQ & Troubleshooting)

1. **ทำไมใน VS Code ถึงมีเส้นหยักสีแดงใต้โค้ด?**
   - **สาเหตุ:** ยังไม่ได้พิมพ์คำสั่ง `npm install` ใน Terminal ทำให้ VS Code ยังมองไม่เห็นโฟลเดอร์ `node_modules`
   - **วิธีแก้:** พิมพ์ `npm install` ใน Terminal แล้วรอให้เสร็จ เส้นสีแดงทั้งหมดจะหายไปทันที

2. **พิมพ์ `npm` แล้วขึ้นว่า command not found?**
   - **สาเหตุ:** คอมพิวเตอร์ของคุณยังไม่ได้ติดตั้ง Node.js
   - **วิธีแก้:** ไปที่เว็บ [nodejs.org](https://nodejs.org/) แล้วดาวน์โหลดเวอร์ชัน LTS มาติดตั้ง จากนั้นปิดและเปิด VS Code ใหม่อีกครั้ง

3. **ต้องการ Build ไฟล์เว็บไปขึ้น Host (Vercel, Netlify, Cloudflare):**
   ```bash
   npm run build
   ```
   ไฟล์เว็บสำหรับขึ้น Server จะถูกสร้างไว้ในโฟลเดอร์ `dist/`
